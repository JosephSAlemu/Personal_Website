Put your own images in this folder.

Anything here is served from the root of your site, so
  public/images/me.jpg   ->   /images/me.jpg

To use your photo as the profile picture, add the file here and set
`avatar` in src/site.config.ts, e.g.

    avatar: '/images/me.jpg',

uchicago.svg and motorola.svg are plain placeholders. Replace them
with the real logo files (keep the same filenames, or update the
paths in src/site.config.ts).
